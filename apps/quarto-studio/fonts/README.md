# 字体来源与许可

`manifest.json` 保存 **16 款开源字体** 的固定来源、版本、SHA256 和字重文件。原有 7 款字体保留，新增思源黑体 SC、思源宋体 SC、霞鹜文楷、文楷屏幕版、未来荧黑、得意黑、更纱黑体 SC、Source Serif 4 和 JetBrains Mono。

运行 `python -X utf8 scripts/download-fonts.py` 准备全部字体。脚本优先复用 `../markdown-studio/fonts/` 中经过校验的文件，缺失时才下载。它同时校验压缩包及提取后的字体文件，使用临时文件完成后再替换。更纱黑体的上游分发格式为 7z，首次准备需本机有 7-Zip，或可读取 7z 的 tar。

字体二进制不提交到 Git，许可证与固定清单会提交。无需将字体安装到 Windows：Web 样张和 Typst 都读取本应用的同一份字体文件。

本机系统字体另有 5 项，按实际安装情况显示。不可用字体会被标记，不能在菜单中选用。霞鹜文楷实际家族名 `霞鶩文楷` 已记录在清单中；英文专用字体的中文使用明确回退。

完整搭配建议、模板、组件和 AI 调用方法见 `../resources/README.md`。实际字体 PDF 样张可以用 `quarto render examples/字体样张.qmd --to typst` 生成。

仓耳今楷02另以 W04 正文、W05 标题两个字重提供，按本机用户声明的个人阅读用途准备，属于独立许可字体。相关来源和原始声明见 [个人字体许可记录](tsanger/LICENSE.txt)，不把它们并入 16 款开源字体数量。
