我们收藏过很多资料，却很少再次打开。问题有时并非内容不够好，而是重点不易辨认、信息缺少层次，阅读还没开始，就已经觉得疲惫。
:::

标题给出问题，章节承接思路。
:::
::: {.kami-metric value="02" label="再进入细节"}
正文、证据与图表各有位置。
:::
::: {.kami-metric value="03" label="最后留下判断"}
把值得回看的结论单独标记。
:::

::: {.kami-takeaway title="这份笔记的核心"}
好的版面应当帮助理解：先给读者方向，再展开细节，最后留下能被记住的结论。字体和颜色服务于这个过程。
:::

## 阅读：给文字一个安静的空间

阅读长文需要连续的节奏。标题回答“这一节在讲什么”，段落围绕一个问题展开，图注交代图像与论点的关系。页面不用每一处都吸引注意，读者才知道应该把精力放在哪里。

### 从层级开始，而不是从装饰开始

把标题、正文、注释放在不同的层级，用稳定的字号和间距建立关系。同一层级始终使用同一种规则，比反复增加边框更容易形成秩序。强调只留给真正需要停顿的位置。

> 留白不是把内容变少，而是让相邻的信息之间，保留可以理解的距离。

这里采用暖纸色与深色文字，强调色只用于导航和重要提示。正文字体保持一致，中文标点与字形自然地构成阅读的纹理。长句应当适度拆分，段落之间也应当留出呼吸。

::: {.kami-note title="个人阅读建议"}
如果一页只有几个短句，先检查是否存在多余的手动分页；如果一页所有地方都很醒目，先减少强调，再考虑增加装饰。
:::

## 研究：把结论与依据放在一起

研究笔记需要更紧凑的信息组织。先说明问题和判断，再列出比较维度，最后记录适用条件。读者可以从摘要进入，也可以直接定位到某一个表格或小节。

### 用相同的问题比较不同方案

下面的表格比较的是阅读任务，并不代表某一种版式在所有场景中更好。选型时应当先考虑读者如何使用这份资料。

| 阅读任务 | 版面重点 | 适合保留的组件 |
|:---|:---|:---|
| 理解一条完整思路 | 顺序与章节关系 | 导语、引语、图注 |
| 对照多个选项 | 条件与判断依据 | 指标、比较表、结论 |
| 分享一个明确观点 | 第一眼与阅读节奏 | 主题页、重点块、步骤 |

::: {.kami-takeaway title="记录判断，也记录边界"}
一条结论应当说明它在什么条件下成立。保留来源、时间和不确定性，能让下次回看这份笔记时，理解当时为什么做出这个判断。
:::

### 从阅读路径组织材料

摘要负责说明方向，正文负责解释过程，表格负责横向比较。这些组件可以有不同的视觉形态，但应当使用同一套颜色和间距规则。视觉上的一致性能够减少寻找信息的成本。

## 分享：让每一页都有一个重点

分享卡片是一段被拆成若干页的叙述。封面提出值得继续阅读的问题，后续页面逐步解释，结尾给出能执行的动作。每一页都需要一个重点，整组页面又必须属于同一个故事。

### 一个可以复用的检查顺序

1. **先检查内容。** 标题是否准确，结论是否有依据，必要的条件有没有保留。
2. **再检查结构。** 页面之间是否存在顺序，图表是否真的帮助解释。
3. **最后检查视觉。** 字号是否易读，边界是否完整，强调有没有过多。

::: {.kami-pullquote}
让内容决定结构，让设计帮助理解。
:::

页面可以有不同风格，但阅读不应当依赖猜测。保留清晰的标题、稳定的正文和可辨认的注释，才能让一份资料在第一次阅读和再次查找时，都保持好用。

::: {.kami-note title="验收时再看一遍"}
从第一页看到最后一页，确认没有重复标题、孤立的小节、被截断的表格，以及只有装饰却没有信息的空页。完整性和阅读节奏同样重要。
:::
