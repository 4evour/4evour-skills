从一张安静的纸开始。底色带来气氛，纹理给出触感，组件让读者知道哪里需要停一停。

::: {.kami-tags}

::: {.kami-takeaway title="先保证好读，再考虑装饰"}
把颜色留给重点，把复杂留给内容。背景可以丰富，文字的对比和组件之间的距离需要保持稳定。
:::

## 给提醒分配不同的语气

信息有轻重，修饰也应当有区别。同样一段文字，可以是补充提示、需要留意的条件，或者值得保留的结论。

::: {.kami-info title="一个小提示"}
在“PDF 纸面与背景”里选择底色和纹理。降低纹理浓度，可以让表格和长段落更清晰。
:::

::: {.kami-alert title="需要留意的边界"}
底色越深，正文越需要足够明亮。使用完整配色预设，比只改纸张颜色更容易保持可读性。
:::

::: {.kami-success title="值得保留的习惯"}
完成修改后，从第一页看到最后一页。检查表格、引语、备注和章节标题的关系，再保存这套样式。
:::

## 让步骤与章节更有秩序

::: {.kami-step value="01" title="选择纸面"}
先选暖纸、浅绿、雾蓝或浅桃，再调整纯色、横线、细点、纤维、柔光与边框。
:::

::: {.kami-step value="02" title="标记内容"}
选中正文后点击“提示、步骤、标签”等按钮。组件会跟随当前配色和外观一起变化。
:::

::: {.kami-divider}
留一点余韵
:::

::: {.kami-pullquote}
装饰的意义，是让重要的内容更容易被看见。
:::

::: {.kami-note title="最后再看一次"}
预览和导出的 PDF 使用相同页面。保留原始文字，让样式成为可以反复选择的阅读方式。
:::
