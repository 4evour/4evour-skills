# 中文排版与分享

好的文档让内容容易理解，也让阅读成为愉快的体验。本页用同一份中文原稿检查不同模板的视觉效果，保留可选择的文字与清晰的层次。

## 字体与颜色

我们可以选择宋体、黑体和文楷，为标题、正文、引用分别搭配字体。强调色用于传达信息，背景和留白帮助建立阅读节奏。

> 设计应当服务于阅读。让重要的信息更清楚，让长文也能舒适地传阅。

## 阅读与分享的检查

完整的文档应当让读者在不同设备上都能轻松理解。封面负责建立第一印象，正文需要清晰的文字、合理的留白和稳定的段落节奏。对复杂内容，可以加入表格、流程图、代码和适当的引用，让读者按自己的速度阅读。

在分享之前，可以检查这些细节：

- **中文是否清晰**：标题、正文和引用各有层次，避免整篇使用装饰字体。
- **内容是否完整**：图片、表格和代码应在页面边界以内，短代码尽量保持在同一页。
- **传播是否方便**：保留完整 PDF；需要发布图文时，再从最终 PDF 导出页面图片。

不必局限于一种纸张。正式传阅可以使用 Letter 或 A4，手机图文可以使用竖版比例；每次改动后都查看实际生成的页面。字体、颜色和结构可以丰富多样，最终仍以阅读舒适、内容清楚为判断依据。
