# 把复杂的内容，讲得清楚一些

> 好的排版帮助读者理解内容，也给文字留出呼吸的空间。

这一篇文章用来检查 **中文字体、引用、表格、公式、代码和流程图**。正文由 Markdown 编写，Quarto 处理文档结构，Typst 负责断行、分页和 PDF 输出。

## 字体和信息层次

- 标题使用独立字体和字号，突出主题。
- 正文保持清晰、舒适的行距，适合持续阅读。
- 引用使用单独的字体、底色和边线，形成阅读停顿。

| 元素 | 表达用途 | 排版选择 |
|------|----------|----------|
| 标题 | 介绍主题 | 独立字体、层级和强调色 |
| 段落 | 解释内容 | 字号、行距和段间距 |
| 引用 | 强调关键观点 | 引用字体和底色 |
| 流程图 | 解释先后关系 | 完整图片和图注 |
