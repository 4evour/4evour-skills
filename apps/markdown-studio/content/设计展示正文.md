# 从字体开始建立层次

同样的文字，换一种字体、调整字号和留白，就会改变阅读感受。**标题负责吸引视线，正文负责持续阅读，引用负责制造停顿。**

```{=typst}
#grid(columns: (1fr, 1fr), column-gutter: 16pt,
  feature-card(number: "01", title: "标题 · 微软雅黑")[粗体、清晰、有力量；承担页面的第一眼。],
  feature-card(number: "02", title: "正文 · 思源黑体")[Noto Sans SC 的中文字形，让长段落保持平稳。],
)
#pull-quote[让内容有节奏，
让重点有自己的位置。]
```

## 一页里的三个阅读速度

先看标题理解主题，再扫小标题找到重点，最后读正文获得细节。让字号、颜色和空白一起完成这个顺序。

```{=typst}
#note-card(title: "字体不需要越多越好")[
  一个页面以两到三种字体为宜。这里用微软雅黑做标题，Noto Sans SC 写正文，楷体表现引用；英文和编号使用 Georgia。
]
#pagebreak()
```

# 用颜色组织信息

背景可以是纯白、暖纸色或深色；正文与背景需要有足够的对比。**一套明确的主题色，比每一段都换颜色更容易形成整体感。**

```{=typst}
#grid(columns: (1fr, 1fr, 1fr), column-gutter: 12pt,
  block(fill: accent, height: 74pt, radius: 8pt, inset: 13pt)[
    #text(fill: paper, size: 13pt, weight: "bold")[强调色]
    #v(6pt)
    #text(fill: paper, size: 10pt)[标题 / 重点 / 标签]
  ],
  block(fill: ink, height: 74pt, radius: 8pt, inset: 13pt)[
    #text(fill: paper, size: 13pt, weight: "bold")[正文色]
    #v(6pt)
    #text(fill: paper, size: 10pt)[信息的主要载体]
  ],
  block(fill: panel, height: 74pt, radius: 8pt, inset: 13pt)[
    #text(fill: ink, size: 13pt, weight: "bold")[卡片底色]
    #v(6pt)
    #text(fill: muted, size: 10pt)[柔和地划分内容]
  ],
)
```

# 让图表成为内容的一部分

表格用于比较，流程图用于解释关系。两者的配色和页面协调，读者便不需要重新适应另一套视觉语言。

| 元素 | 表达目的 | 推荐形式 |
|------|----------|----------|
| 标题 | 抓住主题 | 大字号 + 强对比 |
| 结论 | 快速记住 | 强调色 + 卡片 |
| 比较 | 找到差异 | 统一表头 + 行距 |
| 流程 | 理解先后 | 整图 + 简短标签 |

# 把排版变成稳定的习惯

文字内容和视觉主题分开管理，文章就能持续复用同一套设计。标题、卡片和图表负责变化，页边距、行距和对齐保持稳定。

```{=typst}
#step("01", [先确定内容结构], [明确主题、关键结论和读者下一步要做什么。])
#step("02", [选择一种视觉主题], [暖色杂志适合知识分享；清爽报告适合正式内容；深色卡片适合技术与观点。])
#step("03", [按信息需要加入组件], [引用、卡片、双栏、表格和流程图各自承担明确的表达任务。])
#step("04", [导出并检查整页], [检查长段落、图中文字、分页和颜色。逐页图片可以直接用于视觉核对。])
#pull-quote(by: [写作与设计原则])[好看的排版，
让读者愿意把内容读完。]
```
