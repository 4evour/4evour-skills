# 把日常，写成值得收藏的故事

> 好的排版，有光、有留白，也有自己的语气。

一段文字可以有很多种样子：温柔的宋体、利落的黑体、松弛的手写。颜色与留白让阅读慢下来，让重点被看见。

## 01 · 先为文字选一种气质

- **标题**：用站酷小薇、庆科黄油或毛笔楷书建立第一眼的印象。
- **正文**：用思源黑体、思源宋体或微软雅黑，保持清晰的阅读节奏。
- **引用**：给楷体、行书和手写体一小块安静的位置。

打开左侧的「排版设置 → 字体配色」，分别选择标题、正文和引用字体，右侧会重新排版。

## 02 · 让颜色成为内容的线索

同一篇文章，可以是清爽的白纸，也可以是柔和的紫色或安静的绿色。先选择主题，再微调强调色、背景色和正文色。

| 想表达的感觉 | 字体搭配 | 配色思路 |
| --- | --- | --- |
| 清晰与专业 | 黑体 + 宋体 | 白底、雾蓝、少量强调色 |
| 温柔与日常 | 小薇 + 思源宋体 | 浅紫、暖纸色、柔和对比 |
| 活泼与轻松 | 快乐体 + 黑体 | 明亮点缀、细点纸背景 |

> 颜色不必很多，让它们各自有用途就好。

## 03 · 按你喜欢的节奏阅读

字号、行距、段间距和页边距都能用滑块调整。封面可以与正文融合，也可以独立成一张卡片。

1. 导入或粘贴 Markdown 正文；
2. 选择主题、字体和背景；
3. 看右侧卡片是否清晰、舒展；
4. 导出图片、卡片 PDF，或正式长文 PDF。

**卡片 PDF** 保留右侧画布的视觉效果；**长文 PDF** 会按 Letter 纸张重新排版，适合连续阅读。

让内容决定结构，让设计帮助理解。
