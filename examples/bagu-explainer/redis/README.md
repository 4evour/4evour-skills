## 不作为当前完整模板

当前 [`bagu-explainer` 输出规范](../../../bagu-explainer/references/output-format.md) 要求每模块分为 `### 知识点` 与 `### 面试问答`，每题 Q/A/W 齐全。本例采用 `**知识点**`、`**面经真题**` 和 Q/A，属于历史格式，不满足当前协议。

本例也不包含完整 `claim-ledger.md`、来源核实记录或图片验收结果。版本、命令、数字、题目热度和选型结论不能视为已经针对本次选题核实。

## 推荐用法

- 参考题目组织和历史社交表达，不直接照抄答案或作为可发布成品。
- 新稿结构优先参考 [计算机网络改稿示例](../../tech-writing-zh/computer-network/README.md)。
- 需要迁移 Redis 时，另写符合当前 Q/A/W 的版本，补齐来源、适用版本与审核结果；不要覆盖历史文件冒充原有成品。
