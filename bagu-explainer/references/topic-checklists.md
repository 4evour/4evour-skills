# 主题模块参考清单

这份清单的作用只有一个：**列完题单后查漏**，防止整模块漏掉（"不全面"的教训）。
它不是标准答案，也不限制发挥：

- 用法：先凭面试频率自主列单，再对照本清单查漏——两边都可能对：
  清单外的高频模块（面经、题库可证）照加；清单内与定位不符的模块照砍
- 清单是某一时刻的共识快照，会过时；与联网检索冲突时以检索结果为准
- 主题不在清单内（如消息队列、Spring、并发编程、Dubbo、Netty）：联网检索
  该主题的高频面经与题库，自建同等粒度的清单（模块 + 关键词级考点 + 档位），
  列完同样做查漏
- 不做的模块在题单里注明取舍理由，方便回溯

档位标注（配合 output-format.md 的篇幅规则使用）：
**未标注 = 核心必考**（每场必问，默认保留，砍掉必须注明理由）；
**【高频】** = 常考，默认保留；**【加分】** = 深水区，校招基础向可整块砍掉
或留作下一篇的钩子。

## Redis

1. 选型：为什么用 Redis / vs Memcached / vs 进程内缓存、双层缓存【高频】
2. 线程模型：为什么快、单线程为什么不用加锁、6.0 多线程 I/O 管什么
3. 数据类型与应用：5 基础类型 + Bitmap/HyperLogLog/GEO/Stream，各自的典型场景
4. 场景设计题：排行榜（zset）、点赞/签到（Bitmap）、UV 统计（HyperLogLog）、
   延迟队列（zset）、简单消息队列（List/Stream）至少挑 1-2 个出成题【高频】
5. 底层数据结构：SDS、跳表 vs 平衡树、listpack/quicklist、字典与渐进式 rehash、
   类型底层编码转换【加分】
6. 缓存三兄弟：穿透/击穿/雪崩的现象、方案、代价（三问各成体系，合出也行）
7. 持久化：RDB（fork、写时复制）、AOF（写回策略、重写）、混合持久化、对性能的影响
8. 过期与内存：过期删除（惰性+定期及参数）、8 种淘汰策略、内存碎片【高频】
9. 高可用：主从复制（全量/增量）、哨兵（主观/客观下线、选主）、集群
   （16384 槽、hash tag、MOVED/ASK、为什么不用一致性哈希）【高频】
10. 缓存与数据库一致性：Cache Aside 为什么删缓存、先更库还是先删缓存、
    延迟双删、canal 订阅 binlog
11. 分布式锁：set nx px + 唯一值、看门狗续期、Redlock 争议、主从切换丢锁【高频】
12. 事务与原子性：MULTI/EXEC、为什么不支持回滚、事务 vs Lua vs Pipeline【高频】
13. 大 Key / 热 Key：判定数字、排查命令、治理手段【高频】
14. 排查题：慢查询、CPU 100%、内存占满的排查思路（至少 1 题）【高频】

## MySQL

1. 索引：B+ 树为什么（vs B 树/哈希/跳表）、聚簇与二级索引、回表
2. 索引设计：联合索引与最左前缀、覆盖索引、索引失效场景
3. 事务：ACID 各自靠什么实现、隔离级别与各自问题
4. MVCC：ReadView 规则、版本链、快照读 vs 当前读
5. 锁：行锁/间隙锁/临键锁、死锁排查【高频】
6. 日志：redo/undo/binlog 各自作用、两阶段提交为什么必要
7. SQL 优化：explain 关键列、深分页优化、慢查询治理【高频】
8. 存储引擎：InnoDB vs MyISAM、buffer pool 与 LRU 分代、change buffer【加分】
9. 主从与扩展：复制原理与延迟、分库分表（拆法、分布式 ID、跨库问题）【高频】
10. 场景题：秒杀扣库存防超卖、海量数据 TopK/去重（至少 1 题）【高频】

## JVM

1. 内存区域：运行时数据区各自存什么、对象内存布局、直接内存
2. 对象：创建流程、分配路径（栈上分配/TLAB/堆）、逃逸分析
3. GC 判定：可达性分析、引用类型、方法区回收
4. 垃圾收集器：分代假说、CMS/G1/ZGC 的取舍、三色标记与漏标【高频】
5. 类加载：流程、双亲委派及打破场景【高频】
6. 排查题：OOM 种类与定位、CPU 飙高排查、jstack/jmap/arthas 使用（至少 1 题）【高频】
7. 执行引擎：解释器 + JIT、热点探测【加分】

## 计算机网络

1. 分层模型：OSI/TCP-IP 各层职责与代表协议【高频】
2. TCP 连接：三次握手/四次挥手每步为什么、TIME_WAIT 与 CLOSE_WAIT 堆积、
   半连接/全连接队列
3. TCP 可靠：重传机制、滑动窗口、流量控制、拥塞控制四阶段
4. TCP vs UDP 与各自场景【高频】
5. HTTP：1.1/2/3 演进动机、状态码/方法/缓存头部【高频】
6. HTTPS：TLS 握手流程、证书链、为什么对称+非对称混合
7. 综合题：输入 URL 到页面展示全链路（至少 1 题）【高频】
8. 登录态：cookie/session/token/JWT（至少 1 题）【高频】
9. 其他：粘包拆包、WebSocket【加分】

## 操作系统

1. 进程线程协程：区别与取舍、上下文切换成本、进程状态变迁
2. 进程通信：管道/消息队列/共享内存/信号/socket 的取舍【高频】
3. 调度：常见算法、优先级反转【加分】
4. 同步互斥：互斥实现、信号量、死锁四条件与排查【高频】
5. 内存管理：虚拟内存、多级页表与 TLB、缺页处理、页面置换算法
6. 文件系统：inode、软硬链接【加分】
7. IO：五种 IO 模型、select/poll/epoll 区别、零拷贝（mmap/sendfile）

## Linux/其他后端主题

消息队列（削峰/解耦、丢失/重复/顺序、Kafka/RocketMQ 取舍）、Spring（IOC/AOP、
事务传播、循环依赖）、并发编程（线程池参数与流程、synchronized/锁升级、volatile、
AQS）等，按"联网构造清单再列题"处理，粒度对齐上面的检查表，并给出档位标注。
